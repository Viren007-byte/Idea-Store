# IdeaStore frontend

React, TypeScript, Material UI, Tailwind CSS, and Redux Toolkit.

Run `npm.cmd run dev` and open http://localhost:5173. Start the backend separately;
use `npm.cmd run dev:local` in `backend` for persistent local development without Atlas.

Application entry: `src/main.tsx`. Screens and shared code: `src/app`.

See [the project README](../README.md) for setup, administrator access, API details,
testing, and deployment instructions.
